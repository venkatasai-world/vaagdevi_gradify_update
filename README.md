# 🎓 Vaagdevi v2.0 – Smart Student Portal

**Vaagdevi v2.0** is a modern **full-stack student portal** built to solve real academic challenges faced by students. What started as a small solution to manage personal college marks has now evolved into a **scalable, responsive, and installable student management platform** designed for real student needs.

Created as a **3rd-year CSE (AI & ML) student project**, this platform helps students and faculty manage academic records in a smarter and more organized way.

---

## ✨ About the Project

Initially, this project started with a simple idea — to avoid forgetting **Mid marks during college record submissions** by storing them digitally using JSON files.

Now, **Vaagdevi v2.0** has grown into a complete **full-stack student portal** with modern technologies, real-time data handling, responsive UI, and scalable architecture.

It is designed to make academic marks management easier for both **students and faculty**.

---

## 🔥 Key Features

### 🔐 Secure Authentication
Separate and secure login system for:
- Students
- Faculty

### 📊 Marks Dashboard
Students can view:
- Mid-1 Marks
- Mid-2 Marks
- Subject-wise performance

### 🧑‍🏫 Faculty Marks Management
Faculty can:
- Upload student marks
- Update marks
- Manage academic records easily

### 🔄 Real-Time Data Synchronization
Latest marks and updates are reflected instantly across the system.

### 📱 Responsive UI
Works smoothly on:
- Mobile devices
- Tablets
- Desktop systems

### 📥 PWA Support
Installable as a:
- Mobile App
- Desktop App

Includes:
- Offline support
- App-like experience
- Fast loading

### 📚 Semester Subject Integration
Now includes **CSE (AI & ML) subjects up to 6th semester**, making it useful for students across multiple years.
